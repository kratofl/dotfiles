# Research

1. Define the question and the freshness or authority it requires.
2. Prefer primary sources: official documentation, specifications, source code, papers, and first-party APIs.
3. Trace each material claim to the source that owns it. Distinguish sourced facts from inference.
4. Use the current agent for focused research. Delegate only when the reading is broad enough to benefit from context isolation or parallel independent tracks, and only when user or applicable instructions permit delegation.
5. Answer in the conversation by default. Write a Markdown artifact only when the user requests one or the task explicitly requires a durable report.
6. Cite sources next to the claims they support and note unresolved uncertainty.
